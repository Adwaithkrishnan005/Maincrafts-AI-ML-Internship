# Build-Evaluate-a-Linear-Regression-Model-House-Price-Predictor-
# 🏠 California Housing Price Prediction using Linear Regression

## 📌 Overview

This project demonstrates an end-to-end Machine Learning workflow by building a **Linear Regression** model to predict house prices using the **California Housing Dataset** from Scikit-learn.

The project covers every major step involved in a typical ML pipeline, including data loading, exploratory data analysis (EDA), preprocessing, model training, evaluation, and reporting.

---

## 🎯 Objective

- Understand the complete Machine Learning workflow.
- Build a Linear Regression model for predicting house prices.
- Evaluate the model using standard regression metrics.
- Visualize relationships within the dataset.
- Generate a professional project report.

---

## 📂 Dataset

**Dataset:** California Housing Dataset

Provided by:
- Scikit-learn (`fetch_california_housing()`)

Features include:
- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude

Target:
- Median House Value
